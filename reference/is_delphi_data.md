# Check whether an object is a Delphi data object

Check whether an object is a Delphi data object

## Usage

``` r
is_delphi_data(x)
```

## Arguments

- x:

  Any R object.

## Value

`TRUE` if `x` inherits from `delphi_data`, `FALSE` otherwise.

## Examples

``` r
is_delphi_data(delphi_example)
#> [1] FALSE
```
